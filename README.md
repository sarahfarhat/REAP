# REAP: Repeat Element Assignment Pipeline

REAP is a Nextflow workflow for identifying repetitive elements in biological sequences using BLAST and assigning repeat annotations.

## Overview

The pipeline:

1. Builds a BLAST database from a repeat reference sequence set.
2. Runs BLAST searches for each input sequence file.
3. Assigns repeat annotations based on BLAST hits.
4. Produces per-sample repeat annotation outputs.

---

## Requirements

* Nextflow
* BLAST+ (v2.16 or later)
* Singularity

---

## Input Files

### Repeat Database

A FASTA file containing reference repeat sequences:

```text
repeats.fasta
```

### Input Table

A whitespace-separated file containing:

```text
path/to/sample1.fasta sample1
path/to/sample2.fasta sample2
path/to/sample3.fasta sample3
```

Column 1:

* Path to sequence FASTA file.

Column 2:

* Sample identifier.

---

## Parameters

| Parameter       | Description                                            |
| --------------- | ------------------------------------------------------ |
| `--repeatdb`    | Reference repeat FASTA file                            |
| `--inputTable`  | Table containing sequence FASTA paths and sample names |
| `--query_type`  | Query sequence type (`nucl` or `prot`)                 |
| `--db_type`     | Database sequence type (`nucl` or `prot`)              |
| `--blastevalue` | BLAST E-value threshold                                |
| `--sep`         | Separator used by `sfAssign`                           |

---

## BLAST Program Selection

REAP automatically selects the appropriate BLAST program according to the query and database sequence types.

| Query Type | Database Type | Program |
| ---------- | ------------- | ------- |
| nucl       | nucl          | blastn  |
| nucl       | prot          | blastx  |
| prot       | nucl          | tblastn |
| prot       | prot          | blastp  |

---

## Running REAP

Example:

```bash
nextflow run main.nf \
    --repeatdb repeats.fasta \
    --inputTable samples.tsv \
    --query_type nucl \
    --db_type prot \
    --blastevalue 1e-15 \
    --sep "#"
```

---

## Output

### BLAST Results

```text
01_blastResults/
    sample1.repeats.blastout6
    sample2.repeats.blastout6
    ...
```

### Repeat Annotation Results

Final repeat assignments are generated by the `sfAssign` process. A fasta file without the repeat sequences is also given.
```text
 02_repeatsAssignmentResults/
    sample1.filtered.assignation.id
    sample1.norepeats.fa
    sample2.filtered.assignation.id
    sample2.norepeats.fa
    ...
```
